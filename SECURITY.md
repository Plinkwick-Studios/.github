# Security policy

If you find a security problem in a Plinkwick Studios game, website, or service, please tell us
privately first.

**Email:** [contact@plinkwickstudios.com](mailto:contact@plinkwickstudios.com) with "Security" in
the subject.

Please include what you found, where (game and version, or the page address), and the steps to
reproduce it. We will reply within a few days, keep you posted while we fix it, and credit you when
it ships if you would like that.

Please do not open a public issue, post the details, or access other players' data while testing.
