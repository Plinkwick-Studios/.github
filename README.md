# .github

The public face of the [Plinkwick Studios](https://github.com/Plinkwick-Studios) org.

| File | What it does |
|---|---|
| `profile/README.md` | The org's public profile page |
| `CONTRIBUTING.md` | How invited collaborators work in our (private) repos |
| `SECURITY.md` | How to report a security problem |
| `.github/pull_request_template.md`, `.github/ISSUE_TEMPLATE/` | Default PR and issue templates for repos that do not have their own |

Everything here is public. Do not put unannounced game names, art, or anything secret in this repo.
